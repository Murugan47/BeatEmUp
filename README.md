# BeatEmUp

A fully physics-based sandbox game inspired by *Kick the Buddy*, where players unleash creative destruction on an interactive ragdoll using an arsenal of tools, weapons, and environmental interactions.
Try it here: [![Play Demo](https://img.shields.io/badge/Demo-Click_here-brightgreen)](https://murugan47.github.io/BeatEmUp//)

---

## 🚀 Tech Stack & Architecture

### Frontend & Physics
* **Godot (Web / WebGL):** High-performance client build running smooth browser-based rendering and deterministic physics simulations.
* **GDScript / C#:** Core scripting language managing game loops, input handling, weapon logic, and UI event systems.
* **Godot Physics Engine:** RigidBody dynamics, joint constraints, and collision detection powering responsive ragdoll interactions and object impacts.

---

## 📜 How to Play

* **Enter the Sandbox:** Launch the game directly in your browser with no installation required.
* Option available to install for both Android and Windows.
* **Select Your Arsenal:** Choose from a diverse toolbar at the bottom of the screen—ranging from a **Force Hand** and melee weapons like the **Hammer** and **Axe**, to firearms (**Scar-H**), heavy objects (**iCS Book**), sharp hazards (**Saw Blade**), and cosmic anomalies (**Blackhole**).
* **Interact & Experiment:** Drag, throw, smash, and shoot the character to test out rigid-body physics reactions, cause damage, and rack up points.
* **Toggle Controls & Audio:** Use utility toggles like **Godmode** to customize gameplay rules or manage audio settings directly from the UI toolbar.

---

## ✨ Features

* **Fully Physics-Driven Ragdoll:** Dynamic character limbs and responsive joints that react to every impact, explosion, and external force.
* **Extensive Tool & Weapon Toolbar:** Quick-access selection menu featuring various interactive a cursor for item interactions, Force Hand, Hammer, Axe, Scar-H, iCS Book (explosive), Saw Blade, and Blackhole.
* **Dynamic Health & Score Tracking:** Real-time visual feedback tracking damage dealt to the target.
* **Quality of Life Toggles:** Integrated God-mode and sound toggles for an uninterrupted sandbox experimentation.
